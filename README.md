# HelixFTW_VF Gameplay Mod
Gameplay Mod for HelixFTW. Currently only Yama is adjusted.
/!\ I will only provide files for the mod itself. Go to Alsnapz patreon for the full game. This mod is only compatible with the "Triple Update" free release for now. /!\

## 1. How to install 
- Download modded "Assembly-CSharp.dll" from here.
- In the Triple Update game folder go to HelixFTW_Data -> Managed
- Make a backup copy of the "Assembly-CSharp.dll" in that folder
- Paste the modded file downloaded from here to that folder.
- Start the game and fight Yama. If her name above the health bar is "Yama (VF)" then you're done.
